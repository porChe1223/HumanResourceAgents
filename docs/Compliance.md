# プロトタイプ開発における法的・倫理的配慮ガイドライン

プロトタイプ開発において遵守すべき最低限の法的・倫理的配慮事項を定めます。

## 遵守事項

### データ収集の制限

#### 収集対象（許可）
- **公開情報のみ**
  - GitHub プロフィール・リポジトリ
  - ResearchMap 研究者情報
  - 学会発表資料・論文
  - 公開されている技術ブログ・記事
  - LinkedIn 等の公開プロフィール
  - 企業の公開情報（役員情報等）

#### 収集対象外（禁止）
- **会員制サイト・非公開情報**
  - ログインが必要なサイトの情報
  - 有料会員限定コンテンツ
  - 非公開設定のSNSアカウント
- **センシティブ情報**
  - 住所・居住地詳細
  - 家族構成・個人的な情報
  - 年収・給与情報
  - 健康状態・思想信条に関する情報

### データ処理の安全化

#### データ保持・管理
- **保持期間の制限**
  - 永続化せず、セッションメモリ上で処理

# プロトタイプ開発における法的・倫理的配慮ガイドライン

プロトタイプ開発において遵守すべき最低限の法的・倫理的配慮事項を定めます。

## 遵守事項

### データ収集の制限

#### 収集対象（許可）
- **公開情報のみ**
  - GitHub プロフィール・リポジトリ
  - ResearchMap 研究者情報
  - 学会発表資料・論文
  - 公開されている技術ブログ・記事
  - LinkedIn 等の公開プロフィール
  - 企業の公開情報（役員情報等）

#### 収集対象外（禁止）
- **会員制サイト・非公開情報**
  - ログインが必要なサイトの情報
  - 有料会員限定コンテンツ
  - 非公開設定のSNSアカウント
- **センシティブ情報**
  - 個人の連絡先（電話番号、メールアドレス）
  - 住所・居住地詳細
  - 家族構成・個人的な情報
  - 年収・給与情報
  - 健康状態・思想信条に関する情報

### データ処理の安全化

#### 仮名化処理（必須）
- **実名の匿名化**
  - 実名 → 「候補者A」「候補者B」「研究者001」等
  - 表示・出力時は仮名のみ使用
- **識別情報の暗号化**
  - メールアドレス → ハッシュ化処理
  - ユーザーID → ハッシュ化処理
  - 連絡先情報 → 収集・保存しない

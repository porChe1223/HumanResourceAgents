# Human Resource Agents
要求に対して有望であると考えられる人材を見つけ出すAIエージェント

## 目的
**〜有望人材のレコメンド〜**

近年、人材獲得の競争が激化している。  
従来はウェブサイトからの応募・リファラル・エージェントの活用などに頼っていたが、昨今の各企業は、有望な人材へのダイレクトリクルーティングにも注力するようになった。  
しかし、膨大な数の人材プロフィールを詳細に把握し、加えて職種ごとの専門性や適正を考慮する必要がある中、人事担当者が人力で候補者を発掘し、個別にリクルーティングの案内を送付するのは困難を極める。  
今回は、インターネット上の情報を活用し、人材のプロフィールや活動状況を分析することで、まだアプローチできていない優秀な人材を特定することを目的とする。
